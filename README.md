# Student-Attendance-System
This project automates attendance tracking using face recognition. It helps schools reduce manual effort and improve accuracy. 

Key Features :

* Facial recognition login for students 
* Admin dashboard to view daily reports
* CSV export for attendance logs
* Role-based authentication (Admin/ students/ parents)

Tech Stack :

Python, Machine Learning, SQL
